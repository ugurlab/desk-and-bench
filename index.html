Before you start

How do I use a downloaded tool?

Save the HTML file to your computer and open it in a browser. Task Board is a single file and works without an internet connection. Returning to this website requires internet access.

Where does my data go?

Task Board stores tasks in your browser’s local storage and does not send task data to a server. When you visit this website, GitHub Pages processes normal web requests. This site includes no added analytics or advertising scripts.

What if I find a problem?
